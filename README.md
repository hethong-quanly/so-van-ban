# Sổ văn bản tố tụng

Sổ đến văn bản tố tụng, cài được ra màn hình điện thoại.

**Mở app:** https://hethong-quanly.github.io/so-van-ban/

**File dữ liệu:** `data/so-van-ban-to-tung.json`

## Cài trên điện thoại

- Android (Chrome): mở link, menu ⋮, chọn **Cài đặt ứng dụng** hoặc **Thêm vào màn hình chính**.
- iPhone (Safari): nút **Chia sẻ**, rồi **Thêm vào Màn hình chính**.

## Đưa file vào VKS Cloud

Thư mục: http://vkscantho.vn:8082/vkscloud/index.php/s/c5FnD7c6hRAPVye

Tên miền `vkscantho.vn` chỉ dùng trong mạng viện, không có trên Internet. Trang GitHub chạy HTTPS nên không ghi thẳng được sang máy chủ HTTP của viện.

1. Trong app, bấm **Tải file dữ liệu**. Máy tải về `so-van-ban-to-tung.json` (đây là cả sổ).
2. Máy đang nối mạng viện, mở link thư mục ở trên.
3. Tải file đó vào thư mục chia sẻ.

Sổ đã ghi vẫn nằm trên từng điện thoại. Muốn chuyển sang máy khác, đưa file JSON vừa tải vào thư mục, rồi trên máy kia bấm **Lấy từ kho** khi đang ở mạng viện.
